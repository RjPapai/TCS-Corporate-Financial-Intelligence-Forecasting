# TCS Corporate Financial Intelligence & Forecasting

## Project Overview

TCS Corporate Financial Intelligence & Forecasting is an end-to-end financial analytics project developed using Python, SQL, SQLite and Microsoft Power BI.

The project transforms financial statement data into a structured analytical dataset and an interactive executive dashboard designed to analyze historical financial trends, financial category composition, financial health and future Reserves & Surplus projections.

The project covers the complete analytics workflow from data preparation and validation to SQL analysis, forecasting and business intelligence reporting.

---

## Business Objective

The primary objective of this project is to create a centralized financial analytics solution that can help users understand:

- Long-term financial performance trends
- Financial category composition
- Equity and liability structure
- Major financial indicators
- Project-derived financial health
- Historical financial movement
- Future Reserves & Surplus projections
- Business insights from financial data
